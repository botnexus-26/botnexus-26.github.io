Overview/Introduction
Configured with slash commands, or the dashboard below — your call

Every module your server needs,
run from Discord — or the dashboard.

BotNexus brings welcomer, tickets, levelling, moderation, ER:LC sessions, economy, birthdays, and a full security suite (automod, antinuke, honeytrap) into one bot. Toggle each module with /botconfig, or manage everything from the dashboard instead.

ⓘ

BotNexus works two ways: run /botconfig for an in-Discord setup, or open the web dashboard and manage modules from there. Nothing is locked to one or the other — use whichever fits how you run your server.

What's inside

BotNexus is organized into a handful of module groups, each documented on its own page in the sidebar:

  • Setup — connecting BotNexus to your server, permissions, and the ER:LC integration.
  • Commands — a full reference of every command, grouped by who can run it.
  • Features — welcomer, levelling, moderation, sessions, and every other module, with the settings each one exposes.

How configuration works

Every module in BotNexus follows the same pattern: pick the module, adjust its toggles, channels, and roles, then save. There's no need to memorize flags or arguments — the panel walks you through each option.

Get help

If something isn't behaving the way this documentation describes, the fastest way to get help is the support server. Include your server ID and the module you're configuring so the team can look into it quickly.
