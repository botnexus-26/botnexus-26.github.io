Quick answers

Frequently asked questions.

Is BotNexus free?

Yes. All listed modules are free to invite and use. BotNexus Premium is optional and adds extra features.

How do I set it up?

Invite the bot, then configure modules in Discord with /botconfig. You can also sign in to the web dashboard. The Help Center has guides and demos.

What permissions does it need?

The current invite link requests Administrator access (permissions=8). Review the permissions on Discord's invite screen before approving. Individual features may need permissions such as managing roles or messages, or moderating members.

How does server protection work?

Automod, antinuke, antiraid and webhook protection can be configured separately. Tune sensitivity with /security sensitivity; the optional Honeytrap module can be enabled for spam detection.

What data is saved?

Server configuration, moderation records, API settings and suggestion auto-close settings are stored so they persist between restarts. See the Terms & Policies for the current details.

Can I make custom embeds?

Yes. The dashboard includes an embed builder for Components V2, with configurable colours, banners and divider lines.
