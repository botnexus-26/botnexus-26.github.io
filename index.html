    FAQ

    Is BotNexus free?

    Yes. Every listed module is free to invite and use. Dashboard Premium is an optional £5 one-time purchase in the Store that adds themes, animated backgrounds, effects and tools to the dashboard.

    What permissions does it need?

    The current invite requests Administrator (permissions=8). Individual features may use permissions such as managing roles or messages, or moderating members. Check Discord’s invite screen before approving.

    How does server protection work?

    Automod, antinuke, antiraid and webhook protection are configured separately. Tune strictness with /security sensitivity. The optional Honeytrap module catches spam bots.

    What data is saved?

    Server configuration, moderation records, API settings and suggestion auto-close settings are stored so they persist between restarts. See the Terms & Policies.

    Can I make custom embeds?

    Yes. The dashboard has an embed builder for Components V2 with configurable colours, banners and dividers.

    Something is broken. Where do I look?

    Check the live status card above, then ask in the support server or report a problem.
