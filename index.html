Frequently Asked Questions

Is BotNexus free?

Yes, BotNexus is free to invite and use — all nineteen modules are available with no paywall or subscription required, however we do offer some additional features with our BotNexus Premium package.

How do I configure the bot?

Everything can be configured directly from Discord using /botconfig. Some features are also available through the web dashboard. All of the modules are optional, enable only what your server needs — moderation, security, sessions, and qotd are each configured independently.

What permissions is needed?

BotNexus needs permission to manage roles, send messages, embed links, read message history, and use slash commands. Moderation features also require the ability to kick and ban members. The invite link requests the minimum permissions required for all modules to function - Administrator is usually enough for this

How does the Security module work?

Security tools automatically help protect your server with modern moderation features, anti-slur filtering, logging and configurable protection settings.

Where is my data stored?

BotNexus stores server configuration, moderation records, API keys & suggestion autoclose working between restarts. Data is tied to your Discord server and is not sold or shared with third parties see our policies here .

Do you have a embed generator?

Yes, we have a basic components V2 embed generator on the dashboard that sends on configured bot profile to the channel of your choice, banners customizable - main and footster, all embed colours can be changed in HEX. These are equipped with divider lines on each side. We have this generator for your convienence
