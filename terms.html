01 About BotNexus

BotNexus is an advanced, free-to-use Discord server management and protection bot designed to help communities manage, automate, and protect their servers.

BotNexus provides features including:

  • Server security and protection tools
  • Moderation systems
  • Ticket management
  • Roblox verification
  • Leveling systems
  • Economy features
  • Server automation
  • Custom commands
  • Notifications
  • ER:LC and community management tools

BotNexus is completely free and available for everyone to use. No payment is required to access the core features of the bot.

02 Free Usage

BotNexus is provided as a free service for Discord communities. We reserve the right to add new features, improve existing systems, or change how features operate in future updates.

03 Server Data & Privacy

BotNexus respects server privacy. We cannot view private server information, private messages, private channels, or private conversations. BotNexus only accesses information required for its features and Discord permissions.

The BotNexus dashboard may display basic public server information such as:

  • Server name
  • Server logo/icon
  • Server banner (if available)

BotNexus does not monitor or read private server content unless required for a feature that the server owner has enabled.

04 Server Owner Responsibility

Server owners and administrators are responsible for correctly configuring BotNexus. After adding BotNexus, owners should immediately configure permissions using:

/botconfig

to enable or disable modules. Owners should also configure:

/serversettings

to choose who is allowed to manage BotNexus.

"Run /botconfig any time to turn modules on/off, and /serversettings to choose who's allowed to manage me. Please set permissions ASAP so users cannot manage important commands!"

Failure to configure permissions may allow unwanted users with existing Discord permissions to access commands. BotNexus is not responsible for server raids, damage, moderation issues, or misuse caused by incorrect configuration or failure to set permissions.
